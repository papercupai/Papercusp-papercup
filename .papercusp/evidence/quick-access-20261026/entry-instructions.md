# Open Quick Access

In the Papercusp Server tray menu, open **Quick Panel shortcut** and select a shortcut preset. The shortcut is off on a fresh installation. On Linux, **CmdOrCtrl+Shift+K** means **Ctrl+Shift+K**.

Press your selected shortcut from another application. Quick Access opens in its own native popup with the **Search** tab selected. Type a plan, person, or report name, or narrow the results with **Plans**, **Agents**, or **Reports**. Use the arrow keys to move through results and Enter to open the selected result.

Select a plan to see its progress and people. **Talk** opens that person's conversation inside the popup. **Focus window** activates their exact desktop window when it is available. Select a report and use **Read report** to read it inside the popup.

Escape closes an open report or conversation first. With no nested view open, Escape clears a nonempty search; another Escape dismisses the popup. The Prompts, Brainstorm, and Docs tabs remain available in Quick Panel.

These instructions describe the implemented entry path. Final native verification and release availability are recorded separately in the delivery report.
